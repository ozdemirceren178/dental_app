# 🦷 Dental Tracking System

A desktop dental clinic management application developed using **C# and Windows Forms**. The application is designed to manage patient records, appointments, and treatment information.

## 📌 About the Project

This project was developed to simplify and organize basic dental clinic management processes.

The application allows users to manage patient information, appointments, and treatment records through a desktop-based interface.

## 🚀 Features

* Patient registration and management
* Appointment management
* Treatment information management
* Patient information viewing
* Database operations
* User-friendly desktop interface

## 🛠️ Technologies

* **C#**
* **Windows Forms**
* **Microsoft SQL Server**

## 🗄️ Database

**Microsoft SQL Server** is used to store and manage patient, appointment, and treatment-related data.

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/ozdemirceren178/dental_app.git
```

2. Open the solution file with **Visual Studio**.

3. Create the required database in **Microsoft SQL Server**.

4. Configure the database connection according to your local SQL Server environment.

5. Build and run the application using Visual Studio.

## 🎯 Project Purpose

The purpose of this project is to gain practical experience in **C# desktop application development, Windows Forms, and database management with Microsoft SQL Server**.
